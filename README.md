# 金魚水質管理システム (Goldfish Water Quality Tracker)

金魚飼育における水質管理（水温・pH）の記録・自動診断および時系列推移を可視化するWebアプリケーションです。  
Spring Boot、PostgreSQL、モダンJavaScript、Docker Compose を組み合わせました

---

## 概要・開発背景

- **開発動機:**  
  繊細な水質管理が求められる観賞魚飼育において、日々の水温変化やpH降下（酸性化）を早期に察知し、適切な換水タイミングを判断するために開発しました。
- **主な機能:**
  - **水質測定データの登録・診断:** 水温・pHを入力すると、金魚の至適環境に基づきステータス（適正・警告・換水推奨など）を自動判定
  - **推移ダッシュボード (Chart.js):** 水温とpHの2軸折れ線グラフによるリアルタイム可視化
  - **測定履歴ログ一覧:** 測定日時・水温・pH・診断結果の降順テーブル表示
  - **データ永続化:** コンテナ再起動時もログが消失しないDocker Volume設計
